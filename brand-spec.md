# connectEd brand system

Pinterest-inspired visual discovery meets Apple-like liquid glass: a warm,
image-board posture with one confident red accent, translucent layers, and
restrained spatial motion.

## Core tokens

```css
--bg:      oklch(1.000 0.000 89.9);   /* #ffffff */
--surface: oklch(0.972 0.004 106.5);  /* #f6f6f3 */
--fg:      oklch(0.227 0.021 322.6);  /* #211922 */
--muted:   oklch(0.494 0.011 106.8);  /* #62625b */
--border:  oklch(0.831 0.010 106.6);  /* #c8c8c1 */
--accent:  oklch(0.582 0.236 25.5);   /* #e60023 */
```

## Type

- Display: `"Pin Sans", -apple-system, system-ui, "Segoe UI", sans-serif`
- Body: `"Pin Sans", -apple-system, system-ui, "Segoe UI", sans-serif`
- Mono: `ui-monospace, "SF Mono", "JetBrains Mono", Menlo, monospace`

## Posture

- Project discovery uses a dense masonry rhythm with varied card heights.
- Red is reserved for primary conversion actions and the circular brand mark.
- Glass surfaces use high transparency, background blur, and a single refracted highlight.
- Cards use 28px outer radii; buttons and fields use 16px radii.
- Landing motion is spatial and input-responsive; product-board motion stays restrained.
